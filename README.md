# Proyecto de Integración Continua con GitHub Actions

Este repositorio demuestra el uso de flujos de trabajo automatizados.

## Descripción del Proyecto

El objetivo principal es establecer un entorno colaborativo robusto.
Implementamos un linter automático que verifica la sintaxis de archivos Markdown.

### Características principales

* **Automatización:** Uso de GitHub Actions.
* **Calidad:** Reglas personalizadas.
* **Colaboración:** Modelo de ramas.
