# Proyecto de Integración Continua con GitHub Actions 

Este repositorio ha sido configurado para demostrar el uso de flujos de trabajo automatizados, gestión de ramas mediante **GitFlow** y validación de estándares de documentación.

---

## Descripción del Proyecto
El objetivo principal es establecer un entorno colaborativo robusto. Implementamos un linter automático que verifica la sintaxis de todos los archivos Markdown (`.md`) cada vez que se realiza un envío de código o se abre una propuesta de cambio.

### Características principales:
* **Automatización:** Uso de `GitHub Actions`.
* **Calidad:** Reglas personalizadas en `.markdownlint.json`.
* **Colaboración:** Modelo de ramas basado en Pull Requests.
